# Namen lernen

Web-App zum Trainieren von Namen und Gesichtern auf dem iPhone.

Aktueller Stand: **Sprachtest** (`index.html`). Er prüft, ob die Spracherkennung von Safari
deutsche Namen gut genug erkennt, bevor die eigentliche App gebaut wird.

Läuft über GitHub Pages; in Safari öffnen und über „Teilen → Zum Home-Bildschirm“ ablegen.
